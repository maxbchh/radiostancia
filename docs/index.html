Как пользоваться

1. Нажми СНЯТЬ.
2. Нажми ДСП, ДНЦ, ЛОК или ЛИН для обычного вызова.
3. Для учебной ситуации создай сценарий и запусти его.
4. После входящего вызова сними трубку — реплика будет озвучена.
5. Нажми 🎤 и говори в микрофон либо напиши ответ.
6. Удерживай ТАНГЕНТУ мышью/пальцем во время передачи.
7. КВ/УКВ и канал можно переключать независимо.
